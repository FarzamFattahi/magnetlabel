Ready for training

Strict by default. Exact masks and an export manifest are always included. A YOLO polygon cannot represent holes; COCO RLE preserves them. Validation uses a deterministic image split. Keep related frames in separate projects to avoid leakage.

A faster annotation workflow

  1. Import images and set your class names.
  2. Draw a box for a first mask, or click anchors around the edge with Magnetic. Use Smart polygon for a rough outline that shrinks to foreground, or Lasso assist to draw a freehand loop. Polygon gives manual control.
  3. Press Enter to close an outline. Add or remove pixels with brushes. For assisted selections, paint foreground/background hints and recompute. Manual polygons can also be tightened. Recompute replaces direct brush corrections.
  4. Click Add object. Select an existing object to edit, relabel, or delete it. Editing clears its review status.
  5. Inspect all objects, then Review & next. Reviewing an empty image marks it as a verified negative example.
  6. Export at least two reviewed images. Exact masks accompany the training files.
